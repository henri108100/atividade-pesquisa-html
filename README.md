# Pesquisa de Produtos

Projeto web desenvolvido com HTML, CSS e JavaScript para apresentar uma
interface de pesquisa de produtos.

## Funcionalidades

-   Campo para digitar o termo de pesquisa.
-   Botão **Pesquisar** para enviar a consulta.
-   Botão **Limpar** para limpar a pesquisa.
-   Área principal preparada para exibir produtos em cartões.

## Tecnologias utilizadas

-   **HTML5** --- estrutura da página.
-   **CSS3** --- estilos e apresentação visual.
-   **JavaScript** --- comportamento e lógica da interface.

## Estrutura do projeto

``` text
atividade-pesquisa-html/
├── data/                 # Dados utilizados pelo projeto
├── src/
│   ├── css/
│   │   └── style.css     # Estilos da página
│   └── js/
│       └── script.js     # Lógica da pesquisa
└── index.html             # Página principal
```

## Como executar

1.  Faça o download ou clone este repositório.
2.  Abra a pasta do projeto.
3.  Abra o arquivo `index.html` em um navegador.

Se preferir, utilize a extensão **Live Server** no Visual Studio Code
para executar a página durante o desenvolvimento.
